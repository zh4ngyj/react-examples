## [example-1:类组件](./example-1/)

运行步骤：直接浏览器打开`index.html`

## [example-2:函数组件](./example-2/)
Vite + TypeScript + React

运行步骤：
1. 移动到 `exmaple-1` 目录下
~~~bash
cd exmaple-1
~~~
2. 安装依赖
~~~bash
npm install 
~~~
3. 启动服务
~~~bash
npx vite
~~~
4. 浏览器访问终端输出的地址（默认 http://localhost:5173）
